# testTask

## Unity version 6000.3.12f1

## Краткое описание реализации

### Архитектурные решения
Проект построен на основе компонентно-ориентированного подхода Unity с использованием паттернов **Singleton**, **Static Service** и **Platform-Aware Abstraction** (через интерфейсы и адаптеры).

Основные принципы:
1.  **Абстракция платформы (Platform-Aware):** Весь платформозависимый функционал (Social, Achievements, Presence, Storage) вынесен в интерфейсы. Логика игры не содержит проверок вида `#if platform`.
2.  **Централизованное управление:** Основная логика распределена между специализированными менеджерами (`GameManager`, `WindowManager`).
3.  **Стековая навигация UI:** Реализована система окон на основе стека, что обеспечивает корректное управление фокусом и иерархию интерфейса.
4.  **Безопасность данных:** Слой сохранения данных включает базовое шифрование и работает через абстрактный сервис хранения.

### Устройство сервисов

1.  **PlatformManager & IPlatformService:**
    *   **Bootstrap:** При запуске автоматически определяет платформу и инициализирует соответствующий сервис (`StandalonePlatformService` или `SwitchPlatformService`).
    *   **IAchievementService:** Управляет разблокировкой достижений независимо от API платформы.
    *   **IPresenceService:** Управляет статусом игрока ("В меню", "Играет").
    *   **IStorageService:** Абстракция над `PlayerPrefs` и `SwitchPrefs`, обеспечивающая единый интерфейс сохранения.

2.  **WindowManager (Singleton):**
    *   Управляет жизненным циклом окон (`WindowBase`).
    *   Обеспечивает "заморозку" нижних слоев UI и переключение контекста ввода.
    *   Поддерживает гибридное управление (геймпад/мышь).

3.  **SaveSystem (Static Service):**
    *   Использует `IStorageService` для сохранения `PlayerData`.
    *   Включает XOR-шифрование и поддержку GZip-сжатия строк.

4.  **GameManager & GamePlayManager:**
    *   Высокоуровневая координация игры, использующая `PlatformManager.Service` для взаимодействия с социальными функциями и сохранениями.
